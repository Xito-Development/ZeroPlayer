How to install on Android

1Download the APK

Tap “Download APK”. The file is about the size of a photo album, it takes a few seconds.

2Open it

Open the downloaded file. Android will ask you to allow installing apps from your browser: allow it once.

3Enjoy

ZeroPlayer finds your videos and music by itself. New versions install from inside the app.

Questions

Is it free?

Yes. ZeroPlayer is free, has no ads and doesn't ask you to create an account.

Why isn't it on Google Play?

It's distributed directly as an APK from GitHub, so updates arrive sooner. The app checks for new versions and installs them for you.

Is the APK safe?

The APK is built automatically from the source on GitHub and always signed with the same key, so Android only accepts real updates.

Which version should I choose?

“Download APK” works on almost every phone from 2017 on. Choose the 32-bit one only if the first one doesn't install.
